# TechAprovado V2 — versão para comparação

Esta pasta é uma reformulação da versão original, preservando o conteúdo dos rankings e a tecnologia estática (HTML/CSS/JS).

## Principais mudanças
- identidade visual aplicada de forma consistente;
- banner responsivo com recorte mobile próprio;
- menu mobile acessível;
- home reorganizada para posicionamento, categorias, método e rankings;
- cards de produtos e guias redesenhados;
- páginas de ranking com breadcrumbs, atalhos, leitura mais limpa e links relacionados;
- canonical, Open Graph, Twitter Card e JSON-LD;
- sitemap.xml, robots.txt, manifest e página 404;
- imagens com lazy loading nas áreas não prioritárias;
- JS compartilhado para menu/ano;
- ofertas movidas para js/home.js com data de verificação explícita.

## Para testar localmente
Abra `index.html` diretamente ou sirva a pasta com um servidor HTTP simples.

## Antes de publicar
1. Troque/complete links de redes sociais quando os perfis estiverem definidos.
2. Revise preços e data em `js/home.js`.
3. Revise preços dos rankings, pois são dados editoriais estáticos.
4. Suba todos os arquivos preservando a mesma estrutura de pastas.
